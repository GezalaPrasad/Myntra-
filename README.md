Myntra Clone

A frontend clone of the Myntra e-commerce website, built purely using HTML and CSS — no frameworks or JavaScript.

📌 About the Project

This project recreates the structure and layout of Myntra's website as a static frontend. It focuses on practicing semantic HTML and CSS styling techniques to replicate a real-world, industry-level e-commerce UI.

🛠️ Built With
HTML5 – Page structure and semantic markup
CSS3 – Styling, layout, and responsiveness
✨ Features
Header with navigation bar and logo
Category/menu section
Product listing / banner sections
Footer section
Fully styled using custom CSS (no CSS frameworks used)
📂 Project Structure
myntra-clone/
│
├── index.html          # Main HTML file
├── style.css           # Main stylesheet
└── assets/             # Images and other static assets
🚀 Getting Started
Prerequisites

Just a web browser — no installations or dependencies required.

Running the Project
Clone the repository
   git clone https://github.com/your-username/myntra-clone.git
Navigate to the project folder
   cd myntra-clone
Open index.html in your browser (double-click the file, or use the Live Server extension in VS Code)
